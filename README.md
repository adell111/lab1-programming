# thirst

Проект студента: Адель Хакимов

## Описание

Реализация функции вычисления факториала числа на Python.

## Использование

```bash
python main.py
```

Функция `factorial(n)` принимает неотрицательное целое число и возвращает его факториал. При передаче отрицательного числа выбрасывается `ValueError`.
